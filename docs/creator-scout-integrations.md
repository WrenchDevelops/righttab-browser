# Creator Scout repository capability registry

Audit date: 2026-11-09. Commits below identify the upstream repository snapshots inspected, not installed versions. **YouTube.js is installed and used for public discovery; the remaining repositories are not integrated.** The existing, independently implemented YouTube Data API v3 connector, local saved records/lists, and CSV export are RightTab features; they are not evidence of integration with these projects. Except for YouTube.js, the entries are unavailable at runtime and have no integration tests. Upstream capabilities, dependencies, and licenses need to be verified again before reuse. MIT code requires preservation of its copyright and license notices.

Creator Scout uses YouTube.js public search for discovery and retains YouTube Data API v3 for filtered verification and fallback, configured with an encrypted local API key. It has quota limits. TikTok and Instagram discovery, external contact workers, managed provider fallbacks, and outbound communications are not implemented. Native website contact research is limited to one to three creator-linked hosts, three to nine pages, and public static HTML; source links and uncertainty are retained. Optional model-based ranking is limited to already-extracted public emails, as described below. See [automation-status.md](automation-status.md) for the existing browser automation preview and its restrictions.

## Optional DeepSeek contact ranking

DeepSeek is a separate paid provider, not one of the thirteen repositories. It is disabled by default. If explicitly enabled with an OS-encrypted API key, `deepseek-flash` can rank multiple emails already extracted from a public page. The selected address must exactly match an extracted candidate. At most three calls and $0.01 in conservative estimated peak-rate reservations are allowed per search, with 256 output tokens per call. This is an estimate based on the [published pricing](https://api-docs.deepseek.com/quick_start/pricing/) checked on 2026-11-09, not a billing guarantee; prices can change. Public page excerpts and candidate addresses are sent to DeepSeek when enabled. Automated tests use a mock; live DeepSeek use has not been verified because no key is configured.

## Optional OpenRouter contact ranking

OpenRouter can instead route this same constrained ranking task to `deepseek/deepseek-v4.1-flash-1017`. Its key is stored separately using OS encryption and it is disabled by default. When enabled it takes precedence over direct DeepSeek. Public page excerpts and candidate addresses are sent to OpenRouter and its selected model provider. The same three-call and $0.01 estimated reservation limits apply; a provider price ceiling of $0.30 per million prompt tokens and $1.20 per million completion tokens is requested. Provider availability and prices may change, and estimates are not billing guarantees. The selected address must still match an extracted candidate. A live isolated-profile test through the RightTab panel successfully ranked two public-page candidates in one call; OpenRouter reported a cost of $0.000013398. No outreach was sent.
